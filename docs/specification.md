## データモデル

### CSV ファイル仕様（`data/awamori.csv`）

泡盛データは CSV 形式で管理する。配列データはパイプ（`|`）区切りで格納する。

#### カラム定義

| カラム名 | 型 | 説明 | 例 |
|----------|-----|------|-----|
| `id` | 整数 | 一意のID | `1` |
| `name` | 文字列 | 銘柄名 | `残波（白）` |
| `brewery` | 文字列 | 酒造所名 | `比嘉酒造` |
| `degree` | 整数 | アルコール度数 | `25` |
| `type` | 文字列 | タイプ | `一般酒` / `古酒` / `樽貯蔵` / `ジン（泡盛ベース）` |
| `richness` | 整数(1-5) | コク値 | `2` |
| `sweetness` | 整数(1-5) | 甘さ値 | `3` |
| `flavor` | 文字列 | 風味の説明 | `フルーティーで透明感のある味わい…` |
| `pairing` | 文字列 | ペアリング説明文 | `ゴーヤーチャンプルーや…` |
| `method1_icon` | 絵文字 | 飲み方1のアイコン | `🥤` |
| `method1_name` | 文字列 | 飲み方1の名前 | `炭酸割り` |
| `method1_note` | 文字列 | 飲み方1の補足 | `爽快感MAX` |
| `method2_icon` | 絵文字 | 飲み方2のアイコン | `🍋` |
| `method2_name` | 文字列 | 飲み方2の名前 | `シークヮーサー割り` |
| `method2_note` | 文字列 | 飲み方2の補足 | `南国の香り` |
| `method3_icon` | 絵文字 | 飲み方3のアイコン | `🧊` |
| `method3_name` | 文字列 | 飲み方3の名前 | `ロック` |
| `method3_note` | 文字列 | 飲み方3の補足 | `キレが出る` |
| `pairing_emoji` | 絵文字配列 | 合う料理の絵文字（`\|`区切り） | `🥬\|🍤\|🌿` |
| `pairing_labels` | 文字列配列 | 合う料理のラベル（`\|`区切り） | `炒め物\|揚げ物\|沖縄料理` |
| `pairing_cats` | 文字列配列 | 料理カテゴリーキー（`\|`区切り） | `itamemono\|agemono\|okinawa\|izakaya` |
| `similar` | 文字列配列 | 類似するお酒（`\|`区切り） | `beer\|chuhai\|cocktail` |

#### 銘柄の追加方法
1. `data/awamori.csv` をテキストエディタまたはスプレッドシートで開く
2. 新しい行を追加（全カラムを入力）
3. `richness` / `sweetness` は 1〜5 の整数で指定
4. `pairing_cats` には料理カテゴリーキーをパイプ区切りで指定
5. `similar` には類似するお酒キーをパイプ区切りで指定
6. 保存してブラウザをリロード

#### JSオブジェクトへの変換

CSVは `js/app.js` 内の `parseAwamoriCsv()` 関数で以下の構造に変換される：

```javascript
{
  id: Number,           // 一意のID
  name: String,         // 銘柄名
  brewery: String,      // 酒造所名
  degree: Number,       // アルコール度数
  type: String,         // タイプ（一般酒/古酒/樽貯蔵/ジン）
  richness: Number,     // コク値（1-5）
  sweetness: Number,    // 甘さ値（1-5）
  flavor: String,       // 風味の説明
  pairing: String,      // ペアリングの説明文
  methods: Array<{      // おすすめの飲み方（3パターン）
    icon: String,       //   絵文字アイコン
    name: String,       //   飲み方名
    note: String        //   補足説明
  }>,
  pairingEmoji: Array<String>,   // 合う料理の絵文字
  pairingLabels: Array<String>,  // 合う料理のラベル
  pairingCats: Array<String>,    // 料理カテゴリーキー
  similar: Array<String>         // 類似するお酒の種類
}
```

## レコメンデーションアルゴリズム

### スコア計算

```
score = (5 - |richness - 選択コク値|)
      + (5 - |sweetness - 選択甘さ値|)
      + (料理マッチ ? 3 : 0)
      + (お酒類似 ? 2 : 0)
      + (カクテル選択時のhighball/chuhai類似 ? 1 : 0)
```

### スコア範囲
- 最小: 0（全く合わない）
- 最大: 15（完全一致）

### 出力
- スコア1位: メイン推薦（詳細表示）
- スコア2-3位: 他のおすすめ（簡易表示）

## UI/UXデザイン仕様

### ステップ遷移
- 選択後 360ms でアニメーション開始
- ローディング表示: ステップ間 450ms / 結果表示前 1100ms
- chalk-in アニメーション: 0.4s ease（フェードイン + 上方向スライド）

### プログレスバー（釘デザイン）
- 未完了: 半透明円（rgba(255,255,255,0.1)）
- 進行中: パルスアニメーション（nail-pulse 1.5s）
- 完了: ゴールド塗り潰し（#f5d070）+ グロー

### レスポンシブ対応
- max-width: 540px（アプリコンテナ）
- clamp() による動的フォントサイズ
- タッチ操作対応（-webkit-tap-highlight-color 無効化）

## 非機能要件

### パフォーマンス
- HTML + CSS + JS + CSV の分離構成で保守性と軽量性を両立
- 外部依存: Google Fonts のみ
- JavaScript フレームワーク不使用
- CSVデータは `fetch` で非同期読み込み（GitHub Pages対応）

### セキュリティ
- サーバーサイド処理なし（クライアント完結）
- ユーザーデータの収集・送信なし
- 外部API呼び出しなし

### 可用性
- オフライン動作可能（フォント以外）
- サーバーダウンの影響なし（静的配信）
