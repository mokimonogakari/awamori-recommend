# 泡盛 案内板（Awamori Guide）

好みや料理からぴったりの泡盛を提案する、居酒屋の黒板風レコメンドアプリ

## 概要

4ステップのウィザード形式で、ユーザーの好み（口当たり・甘さ・料理・普段のお酒）に合わせて15種類の泡盛から最適な一杯を提案します。単一HTMLファイルで動作し、サーバー不要で即利用可能です。

## 技術スタック

- **HTML/CSS/JavaScript**（フレームワーク不使用）
- **Google Fonts**: Zen Antique Soft, Kiwi Maru, Noto Sans JP
- **デザイン**: 黒板風UI、木目テクスチャ背景、チョークテイストの文字
- **ホスティング**: GitHub Pages（静的HTML配信）

## セットアップ

## 主な機能

### 4ステップ ウィザード
1. **口当たり** — 軽やか / 濃厚 / どちらでもない
2. **甘さ** — 辛口 / バランス / 甘口
3. **料理** — 9カテゴリーから選択（煮込み、海鮮、ステーキ、スパイシー等）
4. **普段のお酒** — ビール、日本酒、焼酎、ワイン、ウイスキー、カクテル

### レコメンデーション結果
- 銘柄名・酒造所
- 度数・タイプ（一般酒/古酒/樽貯蔵）
- コク・甘さのメーターバー（アニメーション付き）
- おすすめの飲み方（3パターン）
- 合う料理（チップ表示）
- 他のおすすめ（2銘柄）

### レコメンデーションアルゴリズム
1. コク値と甘さ値の距離でベーススコアを計算
2. 選択した料理カテゴリーとのマッチングで加点（+3）
3. 普段のお酒との類似度で加点（+2〜3）
4. 合計スコアの上位を推薦
